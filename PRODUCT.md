# SGB Limit
<!-- impeccable:product-schema 1 -->

## Platform
Windows desktop, native WPF. This project is not a website.

## Users and Purpose
Windows users with AI subscriptions want actual per-product quotas in a floating island, compact details and honest usage forecasts. The package is intended for other users as well as its original requester.

## Confirmed Brief
The user selected SGB Pulse and dark native Windows UI. The latest correction requires a real top-attached Dynamic Island: no gap, square upper corners, mildly rounded lower corners and reliable hover expansion. They rejected the oval floating strip and preferred the earlier taskbar's icons and names. Version2.2 gives all floating styles a circular composition with perimeter quota sectors, restores a taskbar identity style with icons/names, and displays Pro/Max/other reported plan badges on every collapsed panel row. Presentation and customization persist. Account discovery is generic per Windows user; a common email must never merge distinct product quotas.

## Stack
An MIT-licensed TokenTray fork using .NET/WPF. Retains provider integrations, request backoff, cache and taskbar infrastructure. Reads supported local credentials in memory to authenticate quota requests to the respective provider; does not copy credentials into settings. Local caches can contain account and quota metadata. No separate telemetry sender is implemented; this is not an external security audit. Preserve upstream MIT attribution: https://github.com/emrecengdev/tokentray .

## Current Behavior and Limits

Version 2.4 is named SGB Limit. The compact settings sidebar has Görünüm/Hesaplar/Sistem. Görünüm progresses through presentation, related indicator options and placement/common appearance; selecting a mode immediately enters its options. Back preserves draft choices and only the final Save applies them. Indicator cards render fresh synthetic native samples. Signal replaces the selectable Flow instrument, with three/five ascending reception bars representing the displayed used/remaining binding quota, matching the panel. Partial bars preserve small fractions. Invalid readings light no bars. Schema7 only migrates Flow and preserves other user preferences. Legacy storage, mutex and startup aliases preserve upgrades. Dynamic Island has six vertical side docks: left/right top/center/bottom, alongside existing top and bottom horizontal positions. A finite 350 ms geometry spring and content fade/scale preserve geometry during refresh or reversal. Side expansion preserves the original hover footprint. Antigravity Offline results retain same-identified-account last data explicitly stale with original read time; the panel marks those numbers as last reading, never fresh quotas. Taskbar Signal/compact percentages and Dynamic Island retain identified historical values with an asterisk; expired history has no active signal fill. When the IDE is closed a valid stored token can read cloud quota only after email and expiry checks; expired/rejected credentials keep the explicit stale state.
Top-docked Dynamic Island starts at physical y0, upper corners0/lower corners14, with no top border. Bottom docking reverses the corners at the work-area edge; free placement rounds every corner. Native hover reveals full names/limits; departure collapses. Both target dimensions are captured before a resize because changing Width synchronously remeasures the shown WPF tree. First placement occurs before Show and again on Loaded. Shown-window tests verified real enter/leave, resize, data refresh and the animated path; offscreen state tests alone were insufficient for the prior defect. 3/5/8 accounts and +N remain configurable.

Floating is214DIP square/circular at standard scale in Halo, Orbit and Comet: each provider has its own colored sector, icon and percent around a central pulse grip. Taskbar defaults to Identity: thin quota rings containing provider marks, names and a second line of values. Occupied taskbar space first shrinks the named layout, then uses clear icons and a binding percentage for every account; only then does it reduce the visible count with +N. Rings/Ribbon/Dial/Flow remain choices. The410DIP panel shows server-reported plan badges on every row; unknown plans say Plan?, stale plan badges expose last-known status in their tooltip. Details keep limits/resets/advice. v6 migrates only taskbar appearance to icons/names once and preserves selected mode, provider opt-outs and other preferences. Settings remain drafted until atomic Save; a second launch reopens the existing instance. Idle islands have no continuous animation timer and Windows reduced motion is honored.

Claude reads the migrated Claude-Data Microsoft Store profile and existing supported profiles. Modern Antigravity uses the running app's loopback GetUserStatus service, separating Argon from Flash. Grok Bot reads its own current-user encrypted account and weekly quota. Cursor reads its own Cursor billing-period quota. The Grok Bot weekly service is never used as Cursor's allowance. Unknown model-window duration stays unknown. Authentication files are read only; credentials are never copied into app settings.

Provider compatibility depends on upstream services and local login state. The app revisits supported local discovery every five minutes and preserves explicit opt-outs. Live quota integrations cover Claude, Codex, Antigravity, Grok Bot, Cursor, TRAE and configured OpenCode Go. TRAE 3.6 international dollar billing reads its own local login, validates the stored checksum and calls the current v1 ide_user_ent_usage service at an allowed regional TRAE host. Current plan and bonus balances are combined within the same plan, with separate breakdowns; obsolete request limits are not used as dollar usage. Expired/future packs, missing amounts and unsupported billing are not live zeros. Enterprise, CN billing and unrelated paid add-on packages are not covered. Discovery-only catalog entries cover Windsurf, Verdent, Kiro, Gemini, ChatGPT, Perplexity and GitHub Copilot. App presence is never proof of a paid subscription. Web-only subscriptions cannot be verified automatically. Catalog entries open official sites on explicit click. No mailbox scan, embedded receipt or shipped account state is used. Only synthetic demonstration evidence belongs in the public repository.

## Constraints

2.2.1 taskbar correction: preserve all accounts through full, 88-percent named and icon-plus-binding-percent densities before using +N. Never treat an uninitialized or unavailable occupancy sample as free space. Windows 11 centered taskbar geometry supplements UIA when app buttons are missing; an unreadable left-aligned taskbar safely retains tray-only access. Refresh native group bounds without a continuous idle redraw. No settings migration or provider changes.
Independent settings, cache, executable, startup entry and single-instance identity. Preserve authentication boundaries, request backoff, stale-data indicators, keyboard navigation and reduced motion. Never package personal account files or credentials.
